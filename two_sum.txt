# TWO SUM - Test Cases and Solutions

## Problem Description
Given an array of integers `nums` and an integer `target`, return indices of the two numbers such that they add up to target.
You may assume that each input would have exactly one solution, and you may not use the same element twice.
You can return the answer in any order.

**Expected Output:** `0 1`

## Solution Templates

### Python Solution (Correct - Hash Map Approach)
```python
def two_sum(nums, target):
    seen = {}
    for i, num in enumerate(nums):
        complement = target - num
        if complement in seen:
            return [seen[complement], i]
        seen[num] = i
    return []
```

### C++ Solution (Correct - Hash Map Approach)
```cpp
vector<int> twoSum(vector<int>& nums, int target) {
    unordered_map<int, int> seen;
    for (int i = 0; i < nums.size(); i++) {
        int complement = target - nums[i];
        if (seen.find(complement) != seen.end()) {
            return {seen[complement], i};
        }
        seen[nums[i]] = i;
    }
    return {};
}
```

### JavaScript Solution (Correct - Hash Map Approach)
```javascript
function twoSum(nums, target) {
    const seen = new Map();
    for (let i = 0; i < nums.length; i++) {
        const complement = target - nums[i];
        if (seen.has(complement)) {
            return [seen.get(complement), i];
        }
        seen.set(nums[i], i);
    }
    return [];
}
```

## Common Mistakes to Avoid

### ❌ Wrong: Brute Force (will work but slow)
```python
def two_sum(nums, target):
    for i in range(len(nums)):
        for j in range(i + 1, len(nums)):
            if nums[i] + nums[j] == target:
                return [i, j]
    return []
```
**Why wrong?** O(n²) time complexity - inefficient for large inputs

### ❌ Wrong: Returning values instead of indices
```python
def two_sum(nums, target):
    seen = {}
    for num in nums:
        complement = target - num
        if complement in seen:
            return [complement, num]  # ❌ Wrong! Should return indices
        seen[num] = num
    return []
```

### ❌ Wrong: Using same element twice
```python
def two_sum(nums, target):
    seen = {}
    for i, num in enumerate(nums):
        seen[num] = i
    for i, num in enumerate(nums):
        complement = target - num
        if complement in seen:
            return [i, seen[complement]]  # ❌ Might return [i, i]
    return []
```

## Input/Output Format Details

### Input Format (How backend sends data to your code):
```
Line 1: Space-separated integers (the array)
Line 2: Single integer (the target)
```

### Output Format (What your function should return):
```
Two space-separated integers (the indices)
```

Example:
- Input: `2 7 11 15\n9`
- Your function receives: `nums = [2, 7, 11, 15]`, `target = 9`
- Your function returns: `[0, 1]`
- Backend formats as: `0 1`

---

## Debugging Tips

### If you get WRONG_ANSWER:
1. Check if you're returning indices (not values)
2. Check if indices are 0-based (not 1-based)
3. Print your output to see what you're returning
4. Make sure you're not using the same element twice

### If you get RUNTIME_ERROR:
1. Check for array out of bounds access
2. Handle edge cases (empty array, single element)
3. Check data types (int vs long)

### If you get TIME_LIMIT_EXCEEDED:
1. Are you using nested loops? (O(n²))
2. Use hash map approach for O(n) solution

## Time & Space Complexity

### Optimal Solution (Hash Map):
- **Time Complexity:** O(n) - single pass through array
- **Space Complexity:** O(n) - hash map storage

### Brute Force:
- **Time Complexity:** O(n²) - nested loops
- **Space Complexity:** O(1) - no extra storage

**Always use the hash map approach for interviews!** ✨
